# 🏦 Bank Loan Management System (C++)
## 📌 Overview
A console-based C++ project that simulates a bank loan management system with multiple banks. It allows users to apply for loans, calculate EMI, and pay installments with file-based data storage.

---

## ✨ Features
- Multi-bank support (UBL, HBL, MCB)
- Loan application with eligibility checks
- EMI calculation
- Installment payment system
- One active loan per customer
- File handling for data storage

---

## 🛠️ Technologies Used
- C++
- OOP (Inheritance, Polymorphism)
- File Handling

---

## 📁 Data Storage
Loan records are stored in `loans.txt`:

Name | Account No | Loan Type | Amount | Duration | EMI | Remaining Balance

---

## ▶️ How to Run
1. Clone the repository
2. Compile the C++ file
3. Run the executable
4. Use the menu to interact with the system
